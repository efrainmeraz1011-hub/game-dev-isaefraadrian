# Game asset packs

- **[Naval UI v1](naval-ui-v1/README.md)** — first static art pack: 72 PNG sprites and UI pieces, an editable Aseprite atlas, preview, catalog, and import metadata.

These packs contain artwork for review and later UI integration. They do not replace the current renderer automatically. Keep rendering and asset loading in `game/ui/`; the simulation remains independent of artwork.
