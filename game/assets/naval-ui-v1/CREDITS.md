# Artwork origin and credits

| Material | Origin | Treatment |
|---|---|---|
| Selected sprites and room backgrounds | AI-generated through PixelLab MCP for this game project, September 2026 | Palette reduction without dithering; selected shape replacements; one masked stray-pixel repair on the destroyer |
| Reusable UI templates | PixelLab-generated UI sheet | Integer crops and repeated source-pixel strips; no interpolation |
| Dark room icons | Palette variants of the generated HUD glyphs | Same geometry and alpha, darker colors for pale room floors |
| Preview and catalog | Compositions of this pack's selected artwork | Labels and review layouts are separate from the sprites |

[provenance.json](provenance.json) records the selected generation prompts, tool names, stable generation/cleanup job IDs, and final file hashes. The complete original UI sheet and its crop coordinates are retained in [raw/ui_frames.png](raw/ui_frames.png) and [ui-slices.json](ui-slices.json).

FTL informed the requested readability and screen arrangement. No FTL screenshots or extracted FTL sprites are included in this pack. Ship depictions are illustrative game assets and make no claim of historical plan accuracy.

This upload adds no new license grant or public-domain designation for the artwork. License status is unspecified here; this document records origin and processing rather than assigning rights.
