# Source registry

Tiers: **1** primary (official plans, manuals, war diaries, damage reports, official ship histories, national archives). **2** recognized reference works (named naval historians, museum-curated technical pages that cite their documents). **3** curated enthusiast or museum sites and photo archives. Wikipedia is not in the registry; it is a pointer to footnotes only.

Each URL below returned HTTP 200 on 2026-09-11 unless a note says otherwise. Fetch notes matter: some hosts block automated fetches and need a browser tab.
