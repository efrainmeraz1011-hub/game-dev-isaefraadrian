# game-dev-isaefraadrian

Shared repo for Isai, Efrain, and Adrian holding a WWII destroyer roguelite. Two halves: the game design (`WW2_Naval_Roguelite_Game_Logic.md` and `balance_model/`) and a source-cited reference on real WWII warships that the design draws on. The research covers the physical ship, its machinery, its procedures, and its crew's daily life, rather than battle narrative.

## Layout

- `flow/` holds the design, derived from `WW2_Naval_Roguelite_Game_Logic.md` and citing the line behind every rule. **`flow/BUILD.md` is where you start if you are writing game code**: stack, folder layout, build order, stub policy, and a placeholder hull so `OPEN-04` does not block you. `FLOW.md` is the state machine and every branch, with section 16 listing what has no content yet and section 17 listing where the repo contradicts itself. `RULES.md` is the 86 rules the engine implements, each marked `[S…]` sourced, `[period]` believed but unverified, or `[game]` a stated abstraction. `EVENTS.md` is the event and encounter grammar. `CATALOG-EVENTS.md` is 76 situations and four faction missions.
- `warships/INDEX.md` is the navigation entry point: every ship, class, weapon, and facet heading with a link. Generated by `scripts/build-index.py` from each dossier's `meta.json` and headings; never edit it by hand. `warships/index.json` is the same data for programmatic use.
- `scripts/lookup.sh "<term>"` searches every dossier and prints file and line.
- `scripts/check-citations.py` resolves every `[§x.y:NNN]` citation in `flow/` against the live design document and reports drift. The document is edited by several people, and inserting a section silently shifts every line number after it. Run it after any edit to `WW2_Naval_Roguelite_Game_Logic.md`; `--fix` rewrites drifted citations to their section heading for manual checking.
- `scripts/check-events.py` fails an event option that names an unknown resource, an event where every option is gated, a reference to a rule `flow/RULES.md` does not define, or any authored outcome text, which belongs to the rules. Run it after editing `flow/CATALOG-EVENTS.md`.
- `scripts/verify.py` checks the rules of evidence hold; `scripts/check-links.py` checks every link resolves. Run both before committing research.
- `warships/` holds the dossiers, one folder per class under a nation folder; `warships/README.md` explains the facet numbering and lists coverage.
- `skills/ww2-warship-research/` holds the research procedure any agent follows to add or extend a dossier: `SKILL.md` (steps and rules of evidence), `DOSSIER-TEMPLATE.md` (file set and headings), `SOURCES.md` (verified source registry by nation), `QUERIES.md` (search patterns per facet).

## Building the game

One boundary decides everything: **`game/sim/` never knows a screen exists.** No DOM, no
canvas, no colours, no pixel coordinates. `game/ui/` reads state and draws. That is why
placeholder rectangles become sprites later without touching game logic, and why
`headless.ts` can play hundreds of runs with no browser.

Content is data in `game/content/*.json`. Rules are code in `game/sim/rules/`, one file per
rule group named to match `flow/RULES.md`. Adding an event never edits a `.ts` file.

Holes do not block. Stub them with a marker naming the open decision, so
`grep -r "STUB OPEN"` lists the debt. Prefer an obviously wrong placeholder to a plausible
one; a number that looks researched will survive by accident.

## Rules that bind every contributor

Every fact in `warships/` carries a citation to a numbered entry in that dossier's `sources.md`, and the source was fetched, not recalled. A facet with no source is listed in the dossier's `gaps.md` and left empty in the dossier. Wikipedia is followed to its footnotes and never cited itself. Numbers carry their unit and the condition they describe (as designed, as built, a dated refit). Images carry a recorded license in `images/CREDITS.md`. The full rules are in `skills/ww2-warship-research/SKILL.md`.

## Adding a dossier

Read `skills/ww2-warship-research/SKILL.md` and follow its steps. Claude Code loads it as a skill; any other agent reads the file directly.
