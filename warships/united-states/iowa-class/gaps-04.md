## Sonar

Queries run:
- `Iowa class battleship sonar`
- `USS New Jersey BB-62 sonar room battleship sonar equipment WWII`
- `battleshipnewjersey.org "sonar" battleship did battleships have sonar`
- `Iowa class battleship "no sonar" OR "sonar" underwater sound equipment fitted fast battleships USS Missouri QC` (restricted to navweaps.com, navalgazing.net, history.navy.mil, ibiblio.org, maritime.org, navsource.net, battleshipnewjersey.org, ussmissouri.org)
- `"USS Iowa" BB-61 sonar equipment installed 1943 1945 underwater sound`

Sources checked: NavSource photo indexes BB-61, BB-62, BB-63, BB-64 (no occurrence of "sonar" or "sound room" in any caption); navypedia Iowa class electronic equipment lines, as commissioned and for every listed modernization; HyperWar ship data page for BB-62; Battleship Missouri Memorial ship characteristics table; maritime.org document index, including its "Electricity, Communications, Sonar and Radar" section; Battleship New Jersey museum site search; BNJARS reference pages; NAVSEA BB-61 historical evaluation (403).

Result: no source found, 2026-09-12. No fetched source states that the class carried sonar, and no fetched source states that it did not. The class tables and the museum specification sheet list radar without a sonar line, which is silence, not a statement of absence. The dossier records the gap rather than an absence.

Note for a later pass: the Bureau of Ships Electronic Equipment Ship Type Allowance RE-11A-100 (1945), scanned at navy-radio.com, lists the electronic equipment allowance by ship type and is the most likely single document to settle this. The file is 111,783,625 bytes and did not download intact within this session.

## Radio rooms and radio central, wartime arrangement

Sources checked: navy-radio.com BB-62 page and its visitor FAQ sheet, which gives the pre-1980s radio room as third deck just aft of the No. 2 barbette near sick bay but gives no room numbering, no split between transmitter and receiver rooms, and no compartment numbers; nj2bb.org reference index, whose arrangement drawings and space list describe the preserved ship; NHHC photograph 80-G-469927, a dated December 1944 photograph of the New Jersey radio room whose caption names no equipment; HyperWar BB-62 ship data page, which lists no electronics.
