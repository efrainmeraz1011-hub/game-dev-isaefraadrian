# Richelieu class: gaps

One heading per facet. Each entry holds the sub-facets that the facet file records as unsourced, the search protocol for that facet, and the sources checked.

Provenance of the "queries run" lines. For facets 01 to 07 the list is the set of patterns `skills/ww2-warship-research/QUERIES.md` prescribes for that facet, with the ship name substituted; that is the protocol the facet research followed, and the facet file recorded the result. The facet research did not log its query strings verbatim, so these are the protocol patterns rather than a transcript.
