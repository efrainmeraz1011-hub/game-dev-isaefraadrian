# Littorio class: gaps

One entry per sub-facet with no source. Queries were run against the registry in skills/ww2-warship-research/SOURCES.md for Italy and cross-nation, then against the general web, following skills/ww2-warship-research/QUERIES.md.

Registry sources checked for every entry below, unless a narrower list is given: marina.difesa.it (mezzi storici, storia navale, Bollettino d'Archivio, Notiziario della Marina, press releases), regiamarina.net, trentoincina.it, navweaps.com, navypedia.org, commons.wikimedia.org, web.archive.org holdings of regianaveroma.org, ibiblio HyperWar.

## General plans, deck naming and compartment numbering

Queries run: "Littorio booklet of general plans", "Littorio piani generali nave", "corazzata Littorio sezione longitudinale piani", "Littorio class deck plans", "Littorio compartment list", trentoincina.it site search for Littorio, Roma and Vittorio Veneto.
Sources checked: as above. The trentoincina.it ship database pages (dbunita2.php) that formerly held per-ship technical sheets now return 404 for Littorio, Vittorio Veneto, Roma, Italia and Impero; the site's current content is a blog with no class data page.
Result: no source found, 2026-09-12. No general plans booklet, deck naming convention, compartment numbering scheme, bulkhead count or frame spacing was located. Facet 05 records only the spaces named in prose sources.
