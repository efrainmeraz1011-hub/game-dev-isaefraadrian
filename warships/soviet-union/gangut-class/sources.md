# Gangut class: sources

Format: S<n>. Title. Author or institution. Site or publisher, date. URL. Tier. Accessed 2026-09-11. Pages, sheets, or sections used.

Tier 1 is primary (official plans, manuals, war diaries, official records). Tier 2 is a recognized reference work by a named historian. Tier 3 is a curated enthusiast or museum site, or a memoir. Wikipedia is not cited; it was used only to locate footnotes (entry S21).
